# NCKU Git Demo

這是一個用來練習 Git 與 GitHub 基本操作的示範專案。

## 專案目標

- 熟悉版本控制的基本概念。
- 練習新增檔案、提交變更與管理分支。
- 透過 GitHub 分享與協作。

## 開始使用

下載專案：

```bash
git clone https://github.com/YYChen168/261002_ncku_git_demo.git
cd 261002_ncku_git_demo
```

修改檔案後，可以使用以下指令記錄變更：

```bash
git add .
git commit -m "Update project files"
git push
```
